# Resources

Every source below is either first-party (Microsoft Learn or GitHub) or a well-maintained reference. The three Microsoft Learn training modules together cover the full skills-measured outline and are the single most efficient study path.

## Start here (official, exam-specific)

| Resource | Why it matters |
| --- | --- |
| [Exam GH-600 page](https://learn.microsoft.com/en-us/credentials/certifications/agentic-ai-developer/) | Registration, exam policy, domain weights, and the scheduling button. Confirms the exam is generally available and English-language. |
| [GH-600 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-600) | The authoritative skills-measured outline. Treat this as the checklist the whole sprint is graded against. |
| [Exam sandbox](https://ghcertdemo.starttest.com/) | The exact question interface, including interactive question types. Run it before exam day so the format is not a surprise. |

| Module | Maps to |

## Two logistics notes worth acting on early

1. Register with a personal Microsoft account, not a work or school account. The exam page states plainly that records tied to an organisational account are lost and unrecoverable if the holder leaves the organisation.
2. Run the online proctoring system pre-check on the actual machine and network to be used, before booking, if taking the exam online rather than at a test centre.
