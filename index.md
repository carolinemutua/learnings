# Learnings

A collection of self-study kits and learning notes, built diagram-first so concepts are visible, not just described. Each kit maps to a concrete goal, sequences the work day by day, and links back to authoritative sources.

## How the kits are built

Every kit follows the same shape:

1. A short orientation that states what the exam or topic actually measures.
2. A dated plan that fits the available time, weighted toward the heaviest scored areas.
3. Concept pages that lead with a diagram, then explain the flow underneath it.
4. A resources page that points only to first-party or well-maintained sources.

The emphasis is practice-first. Where a concept can be built, the plan says build it rather than only read about it.
